Olist E-Commerce Sales & Business Analytics

An end-to-end data analytics project exploring Brazilian e-commerce operations using PostgreSQL and Power BI.

Project Overview

Analyzed the Brazilian E-Commerce Public Dataset by Olist to uncover insights into sales performance, customer behavior, product trends, delivery operations, payment patterns, and seller performance.

Tools & Technologies

- Kaggle – Dataset Source
- PostgreSQL – Data Management, SQL Analysis & View Creation
- Power BI – Interactive Reporting & Data Visualization

Project Workflow

1. Data Collection: Retrieved and organized 9 datasets from Kaggle.
2. Database Preparation: Imported datasets into PostgreSQL and explored table relationships.
3. SQL Analysis: Performed data analysis and created SQL views for reporting.
4. Power BI Development: Connected the prepared data and developed 9 interactive report pages.
5. Business Analysis: Evaluated key performance indicators and identified business insights.
